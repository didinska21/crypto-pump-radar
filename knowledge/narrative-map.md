# Narrative Map — Peta Narasi Pasar

Narasi = tema yang sedang dicari pasar. Token biasa dengan narasi tepat waktu
sering mengalahkan token bagus dengan narasi basi. Peta ini diperbarui berkala
dari pengamatan X / Square / volume kategori. **Narasi adalah pengali, bukan
dasar** — tanpa gate & momentum, narasi tidak membuat token layak dibeli.

## Cara membaca

- **PANAS** — modal ritel sedang mengalir ke tema ini; token baru bertema ini
  dapat perhatian cepat (dan kompetisinya brutal).
- **HANGAT** — masih ada aliran, selektif.
- **DINGIN** — tema jenuh; token baru butuh katalis luar biasa untuk bergerak.

## Peta per 6 Nov 2026 (pengamatan awal — wajib diperbarui dari data)

| Narasi | Suhu | Catatan |
|---|---|---|
| AI Agent / Agent ID (BSC) | PANAS | Gelombang free-mint Agent ID & token agen memenuhi feed BSC; kualitas sangat beragam — gate menentukan |
| Meme hewan klasik (cat/dog) | HANGAT | Selalu ada, siklus pendek; hanya yang komunitasnya nyata yang bertahan |
| Token "tool/utility" AI | HANGAT | Klaim utilitas wajib dicek — mayoritas hanya label |
| Launchpad & meta-token | DINGIN–HANGAT | Bergantung volume launchpad induknya |

## Aturan pakai

1. Skor narasi (`narrative_fit` 0–10) hanya mengangkat kandidat yang sudah
   lolos gate — tidak pernah menyelamatkan yang gagal.
2. Narasi PANAS menaikkan *kecepatan* perhatian, bukan *probabilitas aman*.
   Justru di narasi panas, token rug paling banyak diproduksi.
3. Peta diperbarui minimal bulanan, atau saat tema baru jelas mendominasi
   volume kategori selama ≥ 3 hari.
