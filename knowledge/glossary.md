# Glosarium

| Istilah | Arti |
|---|---|
| **Pool** | Pasangan perdagangan token di DEX (mis. TOKEN/WBNB) beserta likuiditasnya |
| **Low-cap / micro-cap** | Token berkapitalisasi pasar kecil — gerak besar, risiko besar |
| **Pump** | Kenaikan harga cepat & besar (di repo ini: label ≥ +100% dalam 7 hari) |
| **Rug (pull)** | Likuiditas ditarik / dev kabur / token dibuat tak bisa dijual — modal hilang |
| **Honeypot** | Token yang bisa dibeli tapi tidak bisa dijual |
| **Gate** | Pemeriksaan keamanan lulus/gagal yang wajib dilewati sebelum dinilai |
| **Tier A** | Kandidat terbaik: semua gate lolos + skor ≥ 80 |
| **Tier B** | Gate lolos, skor < 80 — diamati, tidak dibeli |
| **Jalur Momentum** | Jalur skor ≥ 65 + bukti momentum ≥ 2/4 sinyal, gate tetap penuh |
| **Smart money** | Dompet berpengalaman (ESTABLISHED) dengan riwayat keputusan bagus |
| **Cluster fresh** | Sekelompok dompet baru muncul bersamaan — indikasi bundle/insider |
| **Buy pressure** | Dominasi transaksi beli atas jual dalam jendela waktu |
| **Volume/mcap** | Volume perdagangan dibanding kapitalisasi — ukuran aktivitas relatif |
| **LP locked/burn** | Likuiditas terkunci kontrak vesting / dibakar (tidak bisa ditarik) |
| **STANDBY** | Kondisi operasi berhenti menembak (gas/saldo/fail beruntun/limit) |
| **Label** | Vonis hasil akhir kandidat (PUMP/NAIK/DATAR/TURUN/RUG) untuk bahan belajar |
| **Backtest** | Menguji aturan/bobot baru pada data lama sebelum dipakai live |
| **Calibration** | Kesesuaian skor dengan kenyataan: skor tinggi harus terbukti lebih sering pump |
