# Riset Manual per Koin

Tidak semua kandidat datang dari scanner. Lead dari X, grup, atau temuan
manual diteliti dengan format baku sebelum masuk watchlist — supaya riset
bisa dibandingkan dan, yang terpenting, **dilabeli hasilnya nanti**.

## Alur

1. Salin `template-riset-koin.md` → satu file per koin: `YYYY-MM-DD_SIMBOL.md`.
2. Isi semua bagian. Bagian yang tidak bisa diisi = tulis "belum terverifikasi",
   jangan dikosongkan diam-diam dan jangan dikarang.
3. Beri vonis: **PANTAU** (masuk watchlist), **LEWAT** (tidak menarik),
   **HINDARI** (indikasi bahaya — sebutkan buktinya).
4. Setelah 7 hari, isi bagian hasil: label PUMP/NAIK/DATAR/TURUN/RUG +
   pelajaran satu kalimat. Riset tanpa evaluasi = opini yang menumpuk.

## Aturan

- CA hanya dari sumber resmi proyek. CA dari komentar/DM = tidak sah.
- Klaim proyek ("partnership", "audit", "listing soon") dicatat sebagai
  **klaim**, dan kolom verifikasinya diisi terpisah.
- Vonis HINDARI dengan bukti kuat (honeypot terkonfirmasi, LP ditarik, dsb.)
  diusulkan naik ke `knowledge/pattern-library.md` bila polanya berulang.
